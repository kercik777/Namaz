## Что нужно подготовить в Play Console

1. **Значок 512×512** — `docs/play/icon-512.png` (готов).
2. **Графический баннер 1024×500** — `docs/play/feature-graphic.png` (готов).
3. **Скриншоты телефона (2–8 штук)** — снять на устройстве: главная, библиотека, читалка (текст), читалка (режим «Оригинал»), поиск, настройки чтения.
   Требования Play: PNG/JPEG, от 320 до 3840 px по любой стороне, соотношение не длиннее 2:1.
4. **Данные о безопасности (Data safety)** — ответы готовы в `docs/play/data-safety.md`.
5. **Политика конфиденциальности** — `docs/play/privacy-policy.html`, включить GitHub Pages
   (Settings → Pages → Branch: `main`, папка `/docs`), получится адрес вида
   `https://kercik777.github.io/Namaz/play/privacy-policy.html`.
