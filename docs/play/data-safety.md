# Безопасность данных (Data safety) — ответы для Play Console

Приложение работает полностью офлайн и **не имеет ни одного разрешения Android**.
Никакие данные не собираются и никуда не передаются.

## Раздел «Сбор и передача данных»

| Вопрос | Ответ |
|---|---|
| Собирает ли приложение данные пользователей? | **Нет** |
| Передаёт ли приложение данные третьим лицам? | **Нет** |
| Используется ли реклама сторонних сервисов? | **Нет** |
| Используется ли аналитика? | **Нет** |
| Собираются ли данные о местоположении? | Нет |
| Собираются ли личные данные (имя, почта, телефон)? | Нет |
| Собираются ли финансовые данные? | Нет |
| Собирается ли идентификатор устройства? | Нет |
| Собираются ли данные о действиях в приложении? | Нет |
| Есть ли шифрование данных при передаче? | Не применимо: передача данных отсутствует |

## Локальные данные на устройстве

Приложение сохраняет **на самом устройстве** (во внутреннем хранилище приложения):

- прогресс чтения, номер последней страницы;
- закладки;
- сохранённые цитаты;
- историю поиска;
- настройки оформления и чтения.

Эти данные не покидают устройство, не передаются разработчику и удаляются вместе с приложением
(или кнопкой «Сбросить все данные» на вкладке «Ещё»).

## Раздел «Запрос удаления данных»

| Вопрос | Ответ |
|---|---|
| Нужен ли пользователям запрос на удаление данных? | **Нет** — данные хранятся только на устройстве пользователя, разработчик к ним доступа не имеет. Удаляются вместе с приложением. |

## Разрешения приложения

Отсутствуют полностью. В файле `AndroidManifest.xml` нет ни одного тега `<uses-permission>`,
в том числе нет доступа в интернет.

## Обратная связь

При нажатии «Обратная связь» открывается почтовая программа пользователя
(системный `ACTION_SENDTO` с адресом `mailto:`). Письмо отправляется только если пользователь
сам его отправит; приложение ничего не передаёт автоматически.

Кнопка «Поделиться» открывает системное окно выбора приложения с текстом, который выбрал пользователь.

## Дети

Приложение не собирает данные детей, не содержит рекламы, покупок, ссылок на соцсети и
пользовательского контента. Рекомендуемая целевая аудитория — 13+.

## Сторонние библиотеки

Не используются. Только стандартные API Android (framework) и системные шрифты.
